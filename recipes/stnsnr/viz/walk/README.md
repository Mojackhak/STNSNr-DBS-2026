# STN/SNr Walk Visualizations

This publication branch includes the figure-linked subset of the source workflow.
Use `figures/panel_code_map.tsv` for the retained entrypoints and selections.

These scripts generate walking-task figures from
`${MYLFP_PROJECT_ROOT}/summary/stats/walk`.

## Current Grouping Variables

`Hemi` is not used as a visualization grouping, panel, facet, or x-axis
variable in the walk visualization recipes.

- `single_scalar.py` draws raw `Pose-Region`, raw `Pose-Region-Task`, raw
  `Task-Pose-Region`, and normalized `Pose-Region` plots.
- `double_scalar.py` draws raw `Pose`, raw `Pose-Task`, raw `Task-Pose`, and
  normalized `Pose` plots.
- `single_spectral.py` draws raw `Pose-Region`, raw `Pose-Region-Task`, and
  raw `Task-Pose-Region` plots.
- `double_spectral.py` draws raw `Pose`, raw `Pose-Task`, and raw `Task-Pose`
  plots.
- `single_xyz.py` and `double_xyz.py` draw normalized coordinate-fit plots by
  `Pose` and `Region`.

The scalar and spectral scripts no longer generate `Hemi-Pose` or
`Hemi-Pose-Region` figures. Existing legacy files with those names are
preserved unless they are removed outside these scripts.

## Region and Task Split Figures

For any figure involving `Region` and/or `Task`, the scripts keep the combined
overview figure and also write split figures for those variables when they are
not the x-axis variable. If both `Region` and `Task` are eligible, the output
is split by each `Region*Task` combination.
For `Pose-Region-Task`, the single-contact scalar and spectral scripts also
write Task-only split figures that keep `Region` as panels inside each Task
output.

For example:

```text
Pose-Region-STN_raw.pdf
Pose-Region-Task-STN-Walk_raw.pdf
Pose-Region-Task-Single_raw.pdf
Pose-Region-Task-Dual_raw.pdf
Task-Pose-Region-STN_raw.pdf
```

Figures where a variable is the x-axis are not split by that same variable.
For example, `Task-Pose-Region` is split by `Region` but not by `Task`.

The XYZ coordinate-fit scripts also write Pose*Region split figures for their
`zMX/zMY/zMZ-Pose-Region` outputs while keeping the combined and Region-only
figures.

For example:

```text
zMX-Pose-Region-Stand-STN_norm.pdf
zMX-Pose-Region-Walk-SNr_norm.pdf
zMX-Pose-Region-Turn-STN_norm.pdf
```

Use the MyLFP default Conda environment:

## Signed-LogP Layered Heatmaps

`walk_pose_task_pairwise_signed_logp_layered_heatmap.py` renders Task-specific
raw `Pose` pairwise signed-logP heatmaps from the intermediate table produced
by the matching stats workflow. It writes separate layered figures for `Single`
and `Dual` tasks across STN local, SNr local, SNr-/→STN connectivity, and
parameters. These heatmaps use `3.0 x 3.0 mm` cells with black solid cell grid
lines and the shared `visualdf.plot_well_heatmap_grid_df` backend. See
`walk_pose_task_pairwise_signed_logp_layered_heatmap.md` for panel order,
strip labels, and output filenames under `corr/pose_pairwise`.

```bash
conda run -n LFP python recipes/stnsnr/viz/walk/walk_pose_task_pairwise_signed_logp_layered_heatmap.py
```

`walk_task_dual_vs_single_signed_logp_layered_heatmap.py` renders raw `Task`
signed-logP layered heatmaps from the matching Task stats workflow. It writes
one figure per data group, with pose panels ordered as `Sit`, `Stand`, `Walk`,
and `Turn`, under `corr/task_dual_vs_single`. These heatmaps use
`3.0 x 3.0 mm` cells with black solid cell grid lines and the shared
`visualdf.plot_well_heatmap_grid_df` backend.

```bash
conda run -n LFP python recipes/stnsnr/viz/walk/walk_task_dual_vs_single_signed_logp_layered_heatmap.py
```

## LFP-Gait PCA Correlation Heatmaps

`walk_lfp_gait_pca_3m_correlation_heatmap.py` renders three multi-panel
correlation heatmaps for `Task=Single` walk LFP changes versus 3-month gait
PCA distance effects. Pose panels are ordered `Stand`, `Walk`, and `Turn`,
with right strip labels. The renderer uses the shared
`visualdf.plot_well_heatmap_grid_df` backend and matches the pose pairwise
signed-logP heatmap drawing elements. All outputs are written under
`corr/walk_lfp_gait_pca_3m`.

```bash
conda run -n LFP python recipes/stnsnr/viz/walk/walk_lfp_gait_pca_3m_correlation_heatmap.py
```

## MNI Standardized Slope Layered Heatmaps

`walk_mni_standardized_slope_layered_heatmap.py` renders STN and SNr
MNI-coordinate gradient heatmaps from the standardized-slope table generated by
the matching walk stats workflow. Pose panels are ordered `Stand`, `Walk`, and
`Turn`, with right strip labels. The renderer uses the shared
`visualdf.plot_well_heatmap_grid_df` backend so the layered MNI heatmaps keep
the same well-grid, tick, and significance-star style as single-panel well
heatmaps. In addition to the single-coordinate figures, it writes STN and SNr
`mni_xyz` summary figures with Pose rows and `zSTN-x/y/z` or `zSNr-x/y/z`
coordinate columns, plus one combined STN/SNr parameter figure with Pose rows
and Region columns. All outputs are written under `corr/mni_standardized_slope`.

```bash
conda run -n LFP python recipes/stnsnr/viz/walk/walk_mni_standardized_slope_layered_heatmap.py
```
