# Walk LFP-Gait PCA 3-Month Correlation Heatmaps

## Purpose

This visualization renders multi-panel heatmaps for correlations between
walking LFP changes and 3-month gait PCA distance effects.

It reads the correlation workbooks generated by:

```text
recipes/stnsnr/stats/walk/walk_lfp_gait_pca_3m_correlation.py
```

It creates separate heatmaps for:

- `STN`
- `SNr`
- `SNr-STN / SNr->STN`

For each analysis group, the renderer also creates a compact two-row heatmap
that retains only the 3-month STN effect and the incremental 3-month SNr
effect. The original three-row heatmaps remain unchanged.

## Inputs

The renderer reads correlation workbooks from:

```text
${MYLFP_PROJECT_ROOT}/summary/stats/walk/corr/walk_lfp_gait_pca_3m
```

Required workbooks:

- `walk_single_stn_local_gait_pca_3m_corr_by_pose.xlsx`
- `walk_single_snr_local_gait_pca_3m_corr_by_pose.xlsx`
- `walk_single_connectivity_gait_pca_3m_corr_by_pose.xlsx`

Each workbook must contain pose-specific aligned sheets:

```text
Stand_r, Stand_p, Stand_p_raw, Stand_p_adj, Stand_n
Walk_r, Walk_p, Walk_p_raw, Walk_p_adj, Walk_n
Turn_r, Turn_p, Turn_p_raw, Turn_p_adj, Turn_n
```

Heatmap color uses Spearman rho from the `*_r` sheets. Significance stars use
uncorrected p-values from the `*_p_raw` sheets.

## Panel and Axis Labels

Each heatmap has three stacked panels ordered as:

```text
Stand
Walk
Turn
```

The right strip labels the pose panel. Every panel represents an LFP change
relative to `Sit`.

The x-axis uses the same feature order as the statistical workflow. Because
the LFP variables are pose-induced changes, all x-axis LFP labels are
displayed with a leading `Δ`.

Band-level aperiodic power columns are excluded. `Exponent` and `Offset`
remain included in the local STN and SNr heatmaps.

The y-axis labels are:

```text
ΔGait PCA STN vs Pre-op
ΔGait PCA STN+SNr vs Pre-op
ΔGait PCA STN+SNr vs STN
```

The compact heatmaps retain and relabel these source rows:

```text
ΔGait PCA STN vs Pre-op     -> Gait PCA Δ% (STN, 3m)
ΔGait PCA STN+SNr vs STN   -> Gait PCA Δ% (SNr, 3m)
```

The `ΔGait PCA STN+SNr vs Pre-op` row is excluded only from the compact
heatmaps. The source workbooks and original three-row heatmaps are not
modified by this row selection.

The top strip labels are:

```text
STN
SNr
SNr-STN / SNr->STN
```

## Style

Heatmaps use the compact layered heatmap style used by the walking signed-logP
figures and the medication LFP-scale correlation heatmaps. The renderer uses
the shared `visualdf.plot_well_heatmap_grid_df` backend and follows the drawing
elements in `walk_pose_task_pairwise_signed_logp_layered_heatmap.py`:

- symmetric Spearman rho color range from `-1` to `1`;
- `cm.vik` colormap;
- black solid cell grid lines using `linewidth=0.6` and `alpha=0.9`;
- `Spearman's rho` colorbar label;
- significance stars from raw p-values, with non-significant labels hidden.
- white significance stars positioned as in the signed-logP reference;
- x-axis tick labels only on the bottom pose panel;
- y-axis tick labels on every pose panel;
- square `3.0 mm x 3.0 mm` cells.

## Compact Heatmap Contract

- Analytical question: how do walking LFP changes correlate separately with
  the 3-month STN gait-PCA effect and the incremental 3-month SNr effect?
- Chart family: diverging layered heatmap with Stand, Walk, and Turn panels.
- Data footprint: two gait-PCA rows by 38 local features or 30 connectivity
  features in each pose panel.
- Statistical encoding: Spearman rho from `*_r`; stars from uncorrected
  `*_p_raw`; no correlation values or p-values are recomputed.
- Palette and non-color encoding: the existing symmetric `cm.vik` scale,
  black cell borders, pose strips, and significance stars are preserved.
- QA surface: both one-page PDF and RGBA PNG exports are checked for exact row
  labels, panel order, dimensions, and unclipped layout.
