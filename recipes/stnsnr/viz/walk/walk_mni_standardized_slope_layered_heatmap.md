# Walk MNI Standardized Slope Layered Heatmaps

## Purpose

This visualization renders standardized walk MNI-coordinate slope effects as
eleven layered heatmaps. Each single-coordinate or parameter figure stacks three
pose panels:

```text
Stand, Walk, Turn
```

The pose name is shown in the right strip for each panel. Six figures summarize
frequency-resolved metric families:

```text
zSTN-x
zSTN-y
zSTN-z
zSNr-x
zSNr-y
zSNr-z
```

Two additional frequency-resolved summary figures combine all three MNI
coordinates in a `Pose x Coordinate` panel grid:

```text
STN: zSTN-x, zSTN-y, zSTN-z
SNr: zSNr-x, zSNr-y, zSNr-z
```

Two additional figures summarize aperiodic parameters:

```text
STN
SNr
```

One additional aperiodic parameter summary figure combines STN and SNr in a
`Pose x Region` panel grid:

```text
STN, SNr
```

The plotting script does not compute statistics. It reads the standardized
slope table generated by `walk_mni_standardized_slope.py` and renders the
layered panels through the shared `visualdf.plot_well_heatmap_grid_df`
multi-panel well-heatmap backend.

## Input

The required input table is:

```text
${MYLFP_PROJECT_ROOT}/summary/stats/walk/corr/mni_standardized_slope/walk_mni_standardized_slope_values.csv
```

The heatmap value is always `standardized_slope_display`, a clipped version of:

```text
standardized_slope = slope / SD(Value within Band, Region, Pose)
```

Significance stars use the original `rlmer_model` slope `q` column.

## Matrix Layout

For the six frequency-resolved heatmaps, the x-axis order is:

```text
Delta, Theta, Alpha, Beta_low, Beta_high, Gamma
```

The y-axis metric order is:

```text
raw, period, burst-occupation, burst-rate, burst-duration, burst-mean,
coh, wpli, ciplv, delta_net_gc, psi
```

Metric labels are carried through from the standardized-slope table, displayed
with a leading `Δ` to indicate pose-change quantities, and otherwise follow
the existing walk heatmap style.

The combined `mni_xyz` frequency heatmaps arrange pose rows as `Stand`, `Walk`,
and `Turn`, with coordinate columns ordered `x`, `y`, and `z`. Top strips show
`zSTN-x/y/z` or `zSNr-x/y/z`; right strips show the pose labels. Y-axis metric
labels are shown only on the left coordinate column to avoid repeated long
labels.

For the two aperiodic parameter heatmaps, the x-axis order is:

```text
ΔExponent, ΔOffset
```

The y-axis order is:

```text
MNI-x (z-scored)
MNI-y (z-scored)
MNI-z (z-scored)
```

The combined STN/SNr parameter heatmap arranges pose rows as `Stand`, `Walk`,
and `Turn`, with region columns ordered `STN` and `SNr`. Top strips show the
region labels; right strips show the pose labels. Y-axis coordinate labels are
shown only on the left region column to avoid repeated labels.

## Visual Encoding

The heatmaps use:

- `cm.vik`, centered at zero;
- fixed symmetric color limits `[-1, 1]`;
- `3.0 x 3.0 mm` cells for every frequency and parameter figure;
- right strip labels ordered `Stand`, `Walk`, `Turn`;
- top strip style from `visualdf.py` and `viz_defaults.py`;
- the same well-grid, tick, spine, and significance-star drawing core as
  `plot_well_heatmap_df`;
- x-axis tick labels only on the bottom pose panel, while tick locations remain
  present in every panel;
- y-axis tick labels on every single-coordinate and parameter panel, only on
  the left coordinate column in the combined `mni_xyz` frequency heatmaps, and
  only on the left region column in the combined STN/SNr parameter heatmap;
- matching horizontal and vertical panel gaps in the combined `mni_xyz`
  frequency heatmaps and combined STN/SNr parameter heatmap;
- colorbar label `Standardized slope`;
- no direction labels at the colorbar ends.

Stars are:

```text
*   q < 0.05
**  q < 0.01
*** q < 0.001
```
