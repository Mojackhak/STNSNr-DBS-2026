# Walk LFP-FOGQ 3-Month Correlation Heatmaps

## Purpose

This visualization renders layered heatmaps for correlations between walking
LFP pose effects and 3-month FOGQ improvement.

It reads correlation workbooks generated by:

```text
recipes/stnsnr/stats/walk/walk_lfp_fogq_3m_correlation.py
```

Separate heatmaps are produced for:

- `STN`
- `SNr`
- `SNr-STN / SNr->STN`

## Inputs

The renderer reads from:

```text
${MYLFP_PROJECT_ROOT}/summary/stats/walk/corr/walk_lfp_fogq_3m
```

Required workbooks:

- `walk_single_stn_local_fogq_3m_corr_by_pose.xlsx`
- `walk_single_snr_local_fogq_3m_corr_by_pose.xlsx`
- `walk_single_connectivity_fogq_3m_corr_by_pose.xlsx`

Each workbook must contain aligned `r` and `p_raw` sheets for `Stand`, `Walk`,
and `Turn`. Heatmap color uses Spearman rho from `*_r`. Significance stars use
uncorrected p-values from `*_p_raw`, matching the existing Pain-KPPS and Walk
LFP-gait PCA heatmaps. Adjusted p-values remain available in the statistical
workbooks.

## Panel and Axis Contract

Each heatmap contains three stacked pose panels:

```text
Stand
Walk
Turn
```

Every x-axis variable is a walking LFP change relative to `Sit` and therefore
uses a leading Greek capital delta `Δ` (U+0394). Local STN and SNr heatmaps
contain 38 ordered features. The connectivity heatmap contains 30 ordered
features.

The statistical source rows and displayed y-axis labels are:

```text
FOG-Q Δ% (STN, 3m)       -> FOGQ Δ% (STN, 3m)
ΔFOG-Q Δ% (+SNr, 3m)    -> FOGQ Δ% (SNr, 3m)
```

The second displayed row represents incremental improvement from adding SNr
stimulation relative to STN stimulation; it does not represent an SNr-only
protocol.

## Chart Contract

- Analytical question: how do walking LFP pose effects correlate separately
  with the 3-month STN FOGQ improvement and the incremental 3-month SNr
  improvement?
- Chart family: diverging layered heatmap with Stand, Walk, and Turn panels.
- Data footprint: two FOGQ rows by 38 local features or 30 connectivity
  features in each pose panel.
- Statistical encoding: Spearman rho from `*_r`; stars from uncorrected
  `*_p_raw`; no statistics are recomputed by the renderer.
- Palette: symmetric `cm.vik` range from `-1` to `1` with black cell borders,
  white significance stars, and pose strips as non-color structure.
- QA surface: one-page PDF plus RGBA PNG checked for exact Unicode labels,
  panel order, dimensions, and unclipped layout.

## Outputs

Outputs are written to the same dedicated directory:

```text
${MYLFP_PROJECT_ROOT}/summary/stats/walk/corr/walk_lfp_fogq_3m
```

Generated files:

- `walk_single_stn_local_fogq_3m_corr_heatmap.pdf`
- `walk_single_stn_local_fogq_3m_corr_heatmap.png`
- `walk_single_snr_local_fogq_3m_corr_heatmap.pdf`
- `walk_single_snr_local_fogq_3m_corr_heatmap.png`
- `walk_single_connectivity_fogq_3m_corr_heatmap.pdf`
- `walk_single_connectivity_fogq_3m_corr_heatmap.png`

Rerunning the renderer rewrites only these six heatmap files and does not
modify the source workbooks or the existing gait-PCA figures.

## Run Command

Use the MyLFP default Conda environment:

```bash
conda run -n LFP python recipes/stnsnr/viz/walk/walk_lfp_fogq_3m_correlation_heatmap.py
```
