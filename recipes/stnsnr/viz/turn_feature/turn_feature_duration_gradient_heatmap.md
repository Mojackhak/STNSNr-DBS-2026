# Turn Feature Duration Gradient Heatmaps

## Purpose

This renderer plots standardized turn-duration gradient effects from the
long-form table generated by `turn_feature_duration_standardized_slope.py`.

It creates four two-panel heatmaps and one frequency summary heatmap:

- `STN local`
- `SNr local`
- `Connectivity`
- `Params`
- `Frequency summary`

## Input

The renderer reads:

```text
${MYLFP_PROJECT_ROOT}/summary/stats/turn_feature/corr/duration_standardized_slope/turn_feature_duration_standardized_slope_values.csv
```

The plotted value is `standardized_slope_display`; significance stars use the
`q` column from the source `rlmer_model` slope tables.

## Layout

Frequency figures use a one-row, two-column panel grid with top strips that
combine the region or connection group with the gradient component:

```text
STN_between, STN_within
SNr_between, SNr_within
SNr-/→STN_between, SNr-/→STN_within
```

The subscript text corresponds to the full source predictors
`z_Feature_between*_Duration` and `z_Feature_within*_Duration`. The figure does
not use a right strip.

Frequency heatmaps use metric rows and frequency-band columns. Displayed
frequency metric rows use a leading `Δ` because the plotted LFP values are
changes relative to Stand, for example `ΔTotal power` and `ΔPSI`. The params
heatmap remains separate: it uses top strips `SNr`, `STN`, rows `Between`,
`Within`, and columns `ΔExponent`, `ΔOffset`. These prefixes are display-only;
the stats audit table keeps its original `metric_label` and `parameter_label`
values.

The frequency summary heatmap combines the local and connectivity frequency
groups into a variable-height `3 x 2` panel grid. Its top strips are `Between`
and `Within`; its right strips are `SNr`, `STN`, and `SNr-/→STN`. The first two
panel rows keep the six local metric rows, and the connection row keeps the
five connectivity, GC, and PSI metric rows. Each panel still uses `3.0 x 3.0 mm`
cells.

## Visual Encoding

The heatmaps use:

- `cm.vik`, centered at zero;
- fixed symmetric color limits `[-1, 1]`;
- `3.0 x 3.0 mm` cells;
- the shared `visualdf.plot_well_heatmap_grid_df` backend;
- colorbar label `Standardized slope of ΔLFP (Turn - Stand) per z-scored turn duration`;
- white q-value significance stars.
