# FOG Pose Pairwise Signed-LogP Layered Heatmaps

## Purpose

This visualization renders raw FOG `Pose` pairwise signed-logP heatmaps from
the intermediate table generated by:

```text
recipes/stnsnr/stats/fog/fog_pose_pairwise_signed_logp.py
```

## Input

The renderer reads:

```text
${MYLFP_PROJECT_ROOT}/summary/stats/fog/corr/pose_pairwise/fog_pose_pairwise_signed_logp_values.csv
```

The input table must use `rlmer_model` sources and source contrasts
`Stand - Walk`, `Stand - FoG`, and `Walk - FoG`.

## Figure Layout

All heatmaps use:

- three layered panels with right strips ordered `Stand vs Walk`,
  `Stand vs FoG`, `Walk vs FoG`;
- `3.0 x 3.0 mm` cells;
- black solid grid lines;
- display values clipped to `[-3, 3]`;
- the shared `visualdf.plot_well_heatmap_grid_df` backend.

Frequency-band columns are ordered as:

```text
Delta, Theta, Alpha, Beta_low, Beta_high, Gamma
```

The renderer creates original and transposed heatmaps for:

- `STN`
- `SNr`
- `SNr-/→STN`
- `Params`

It also creates an additional Params-by-comparison heatmap. This figure uses
top strips ordered `Stand vs Walk`, `Stand vs FoG`, `Walk vs FoG`; each panel
uses `Exponent` and `Offset` as y-axis rows and `SNr`, `STN` as x-axis columns.
The existing Params original and transposed heatmaps are still rendered.

The intermediate CSV may contain the `Aperiodic power` local metric, but this
metric is omitted from all rendered heatmaps.

It also creates two combined summary heatmaps for `SNr`, `STN`, and
`SNr-/→STN`. Params are not included in the combined summary heatmaps.

The combined `freq_by_param` summary uses right strips ordered
`Stand vs Walk`, `Stand vs FoG`, `Walk vs FoG`; top strips ordered `SNr`,
`STN`, `SNr-/→STN`; y-axis bands; and x-axis metric labels.

The combined `param_by_freq` summary uses right strips ordered `SNr`, `STN`,
`SNr-/→STN`; top strips ordered `Stand vs Walk`, `Stand vs FoG`,
`Walk vs FoG`; x-axis bands; and y-axis metric labels.

## Encoding

The shared colorbar is labeled:

```text
Signed (b-a) -log10(p_Tukey) (a vs b)
```

For a panel labeled `a vs b`, positive values mean `b > a`.
Significance stars come from `p_tukey`.

## Outputs

Heatmap files are written to:

```text
${MYLFP_PROJECT_ROOT}/summary/stats/fog/corr/pose_pairwise
```

Generated heatmap basenames:

- `fog_pose_pairwise_stn_local_signed_logp_layered_heatmap`
- `fog_pose_pairwise_snr_local_signed_logp_layered_heatmap`
- `fog_pose_pairwise_connectivity_signed_logp_layered_heatmap`
- `fog_pose_pairwise_params_signed_logp_layered_heatmap`
- `fog_pose_pairwise_stn_local_signed_logp_freq_by_param_layered_heatmap`
- `fog_pose_pairwise_snr_local_signed_logp_freq_by_param_layered_heatmap`
- `fog_pose_pairwise_connectivity_signed_logp_freq_by_param_layered_heatmap`
- `fog_pose_pairwise_params_signed_logp_transposed_layered_heatmap`
- `fog_pose_pairwise_params_by_comparison_signed_logp_heatmap`
- `fog_pose_pairwise_summary_freq_by_param_signed_logp_layered_heatmap`
- `fog_pose_pairwise_summary_param_by_freq_signed_logp_layered_heatmap`

Each basename is exported as PDF and PNG.

## Run Command

Use the MyLFP default Conda environment:

```bash
conda run -n LFP python recipes/stnsnr/viz/fog/fog_pose_pairwise_signed_logp_layered_heatmap.py
```
