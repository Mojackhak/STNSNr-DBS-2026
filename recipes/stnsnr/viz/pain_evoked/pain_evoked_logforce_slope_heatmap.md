# Pain Evoked LogForce Slope Heatmap

## Purpose

This visualization renders pain-evoked raw `LogForce_c` slope heatmaps from the
audit table generated by:

```text
recipes/stnsnr/stats/pain_evoked/pain_evoked_logforce_slope.py
```

It uses `src.viz.visualdf.plot_well_heatmap_grid_df`.

## Figure Layout

The summary heatmap is a `3 x 2` panel grid:

- top strips: `ONS`, `OFS`;
- right strips: `SNr`, `STN`, `SNr-/→STN`;
- x-axis: `Duration`, `Onset time`, `Offset time`, `Peak time`, `Peak value`,
  `AUC`, `Rise slope`, `Fall slope`;
- SNr y-axis: `ΔTotal power δ`, `ΔPeriodic power δ`, `ΔTotal power θ`,
  `ΔPeriodic power α`, `ΔPeriodic power Low-β`, `ΔExponent`, `ΔOffset`;
- STN y-axis: `ΔTotal power δ`, `ΔPeriodic power δ`, `ΔTotal power θ`,
  `ΔPeriodic power α`, `ΔPeriodic power Low-β`, `ΔPeriodic power γ`,
  `ΔExponent`, `ΔOffset`;
- SNr-/→STN y-axis: `ΔCoherence δ`, `ΔwPLI δ`.

The `ΔwPLI δ` `OFS` cells are retained and rendered like the other slope
cells.

## Visual Encoding

The heatmap uses:

- `cm.vik`, centered at zero;
- fixed symmetric color limits `[-1.3, 1.3]`;
- `3.0 x 3.0 mm` cells;
- q-based white significance stars;
- x-axis tick labels only on the bottom panel row;
- y-axis tick labels only on the left phase column;
- colorbar label
  `Slope of evoked ΔLFP metric per centered log10(Force)`.

## Outputs

Outputs are written to:

```text
${MYLFP_PROJECT_ROOT}/summary/stats/pain_evoked/corr/logforce_slope
```

Generated files:

- `pain_evoked_logforce_slope_summary_heatmap.pdf`
- `pain_evoked_logforce_slope_summary_heatmap.png`

## Run Command

Use the MyLFP default Conda environment:

```bash
conda run -n LFP python recipes/stnsnr/viz/pain_evoked/pain_evoked_logforce_slope_heatmap.py
```
