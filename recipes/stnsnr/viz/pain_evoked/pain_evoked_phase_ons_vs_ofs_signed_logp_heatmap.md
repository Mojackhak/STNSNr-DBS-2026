# Pain Evoked Phase ONS-vs-OFS Signed-LogP Heatmap

## Purpose

This visualization renders pain-evoked `Phase` ONS-vs-OFS signed-logP
heatmaps from the intermediate table generated by:

```text
recipes/stnsnr/stats/pain_evoked/pain_evoked_phase_ons_vs_ofs_signed_logp.py
```

It uses `src.viz.visualdf.plot_well_heatmap_grid_df`.

## Figure Layout

The default summary heatmap is a `3 x 1` panel grid:

- top strip: `ONS vs OFS`;
- right strips: `SNr`, `STN`, `SNr-/→STN`;
- x-axis: `Duration`, `Onset time`, `Offset time`, `Peak time`, `Peak value`,
  `AUC`, `Rise slope`, `Fall slope`;
- SNr y-axis: `ΔTotal power δ`, `ΔTotal power θ`, `ΔExponent`, `ΔOffset`;
- STN y-axis: `ΔTotal power δ`, `ΔPeriodic power δ`, `ΔTotal power θ`,
  `ΔPeriodic power α`, `ΔPeriodic power Low-β`, `ΔPeriodic power γ`,
  `ΔExponent`, `ΔOffset`;
- SNr-/→STN y-axis: `ΔCoherence δ`, `ΔwPLI δ`.

The region-top summary heatmap is the horizontal companion layout:

- top strips: `SNr`, `STN`, `SNr-/→STN`;
- top-strip font size: `7 pt`;
- top-strip height: shared default `cfg.strip_top_height_mm`;
- no right strip;
- y-axis: waveform parameters, `Duration`, `Onset time`, `Offset time`,
  `Peak time`, `Peak value`, `AUC`, `Rise slope`, `Fall slope`;
- x-axis: group-specific electrophysiological metrics, such as
  `ΔTotal power δ`, `ΔExponent`, `ΔCoherence δ`, and `ΔwPLI δ`.

## Visual Encoding

The heatmap uses:

- `cm.vik`, centered at zero;
- fixed symmetric color limits `[-3, 3]`;
- `3.0 x 3.0 mm` cells;
- top-strip height and right-strip width matched to the pain Lat heatmap
  defaults, `cfg.strip_top_height_mm` and `cfg.strip_right_width_mm`;
- black solid grid lines;
- white significance stars from `p_tukey`;
- colorbar label `Signed (ONS-OFS) -log10(p_Tukey)`;
- colorbar endpoint labels `ONS > OFS` and `ONS < OFS`;
- extra spacing between the right strips and the colorbar so the long
  `SNr-/→STN` strip and endpoint labels remain separated.
