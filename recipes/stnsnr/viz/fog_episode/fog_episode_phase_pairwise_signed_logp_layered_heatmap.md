# FOG Episode Phase Pairwise Signed-LogP Layered Heatmaps

## Purpose

This visualization renders raw FOG-episode `Phase` pairwise signed-logP
heatmaps from the intermediate table generated by:

```text
recipes/stnsnr/stats/fog_episode/fog_episode_phase_pairwise_signed_logp.py
```

## Input

The renderer reads the default non-Delta table:

```text
${MYLFP_PROJECT_ROOT}/summary/stats/fog_episode/corr/phase_pairwise/fog_episode_phase_pairwise_signed_logp_values.csv
```

It also reads the with-Delta table for the additional `_with_delta` banded
heatmaps:

```text
${MYLFP_PROJECT_ROOT}/summary/stats/fog_episode/corr/phase_pairwise/fog_episode_phase_pairwise_signed_logp_values_with_delta.csv
```

The input table must use raw non-Hemi `rlmer_model` sources and source
contrasts `BL - Pre`, `BL - ONS`, and `Pre - ONS`.

## Figure Layout

All heatmaps use:

- three layered panels with right strips ordered `BL vs Pre`, `BL vs ONS`,
  `Pre vs ONS`;
- `3.0 x 3.0 mm` cells;
- black solid grid lines;
- display values clipped to `[-3, 3]`;
- the shared `visualdf.plot_well_heatmap_grid_df` backend.

Default frequency-band columns exclude `Delta` and are ordered as:

```text
Theta, Alpha, Beta_low, Beta_high, Gamma
```

The additional `_with_delta` banded heatmaps use:

```text
Delta, Theta, Alpha, Beta_low, Beta_high, Gamma
```

Missing burst duration and burst amplitude cells are displayed as blank cells.

The renderer creates original and transposed heatmaps for:

- `STN`
- `SNr`
- `SNr-/→STN`
- `Params`

It also creates an additional Params-by-comparison heatmap from the default
non-Delta input table. This figure uses top strips ordered `BL vs Pre`,
`BL vs ONS`, `Pre vs ONS`; each panel uses `Exponent` and `Offset` as y-axis
rows and `SNr`, `STN` as x-axis columns. The existing Params original and
transposed heatmaps are still rendered.

The intermediate CSV may contain the `Aperiodic power` local metric, but this
metric is omitted from all rendered heatmaps.

It also creates two combined summary heatmaps for `SNr`, `STN`, and
`SNr-/→STN`. Params are not included in the combined summary heatmaps.

The combined `freq_by_param` summary uses right strips ordered `BL vs Pre`,
`BL vs ONS`, `Pre vs ONS`; top strips ordered `SNr`, `STN`, `SNr-/→STN`;
y-axis bands; and x-axis metric labels.

The combined `param_by_freq` summary uses right strips ordered `SNr`, `STN`,
`SNr-/→STN`; top strips ordered `BL vs Pre`, `BL vs ONS`, `Pre vs ONS`;
x-axis bands; and y-axis metric labels.

## Encoding

The shared colorbar is labeled:

```text
Signed (b-a) -log10(p_Tukey) (a vs b)
```

For a panel labeled `a vs b`, positive values mean `b > a`.
Significance stars come from `p_tukey`.

```text
${MYLFP_PROJECT_ROOT}/summary/stats/fog_episode/corr/phase_pairwise
```

- `fog_episode_phase_pairwise_stn_local_signed_logp_freq_by_param_layered_heatmap`
- `fog_episode_phase_pairwise_snr_local_signed_logp_freq_by_param_layered_heatmap`

- `fog_episode_phase_pairwise_summary_param_by_freq_signed_logp_layered_heatmap`

- `fog_episode_phase_pairwise_snr_local_signed_logp_layered_heatmap_with_delta`

- `fog_episode_phase_pairwise_summary_param_by_freq_signed_logp_layered_heatmap_with_delta`

Each with-Delta basename is exported as PDF and PNG. Params are not duplicated
with `_with_delta` because Params have no band axis.

## Run Command

Use the MyLFP default Conda environment:

```bash
conda run -n LFP python recipes/stnsnr/viz/fog_episode/fog_episode_phase_pairwise_signed_logp_layered_heatmap.py
```
