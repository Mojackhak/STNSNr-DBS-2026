# Turn Lat Contra vs Ipsi Signed-LogP Heatmaps

## Purpose

This visualization renders turn `Lat` signed-logP heatmaps from the
intermediate table generated by:

```text
recipes/stnsnr/stats/turn/turn_lat_contra_vs_ipsi_signed_logp.py
```

It creates separate heatmaps for:

- `STN`
- `SNr`
- `SNr-/→STN`
- `Params`

## Input

The renderer reads:

```text
${MYLFP_PROJECT_ROOT}/summary/stats/turn/corr/lat_contra_vs_ipsi/turn_lat_contra_vs_ipsi_signed_logp_values.csv
```

The input table must use `rlmer_model` sources and source contrast
`Ipsi - Contra`. Positive signed-logP values mean `Contra < Ipsi`.

## Figure Layout

All heatmaps use `3.0 x 3.0 mm` cells with black solid grid lines. Display
values are clipped to `[-3, 3]`.

Frequency-band columns are ordered as:

```text
Delta, Theta, Alpha, Beta_low, Beta_high, Gamma
```

The parameter heatmap uses columns `Exponent` and `Offset`, with rows `SNr` and
`STN`.

## Encoding

The shared colorbar is labeled:

```text
Signed -log10(p_Tukey)
```

The colorbar endpoint labels are:

```text
Ipsi > Contra
Ipsi < Contra
```

Endpoint labels are positioned with extra spacing from the central colorbar
label so they remain legible on `3.0 x 3.0 mm` cell heatmaps.

Significance stars come from `p_tukey`.

## Outputs

Heatmap files are written to:

```text
${MYLFP_PROJECT_ROOT}/summary/stats/turn/corr/lat_contra_vs_ipsi
```

Generated heatmaps:

- `turn_lat_stn_local_contra_vs_ipsi_signed_logp_heatmap.pdf`
- `turn_lat_stn_local_contra_vs_ipsi_signed_logp_heatmap.png`
- `turn_lat_snr_local_contra_vs_ipsi_signed_logp_heatmap.pdf`
- `turn_lat_snr_local_contra_vs_ipsi_signed_logp_heatmap.png`
- `turn_lat_connectivity_contra_vs_ipsi_signed_logp_heatmap.pdf`
- `turn_lat_connectivity_contra_vs_ipsi_signed_logp_heatmap.png`
- `turn_lat_params_contra_vs_ipsi_signed_logp_heatmap.pdf`
- `turn_lat_params_contra_vs_ipsi_signed_logp_heatmap.png`

## Run Command

Use the MyLFP default Conda environment:

```bash
conda run -n LFP python recipes/stnsnr/viz/turn/turn_lat_contra_vs_ipsi_signed_logp_heatmap.py
```
