# Med LFP-Scale Delta Percent Correlation Heatmaps

## Purpose

This visualization renders medication LFP-scale improvement-rate correlation
heatmaps from the correlation workbooks generated by:

```text
recipes/stnsnr/stats/med/med_scale_correlation.py
```

It creates separate heatmaps for:

- `STN`
- `SNr`
- `SNr-STN / SNr->STN`

The workflow retains the original heatmaps with separate rest- and
action-tremor rows and also creates a second set in which those rows are
replaced by one combined `Tremor Δ%` row.

## Inputs

The renderer reads correlation workbooks from:

```text
${MYLFP_PROJECT_ROOT}/summary/stats/med/corr
```

Required workbooks:

- `med_stn_local_scale_delta_percent_corr.xlsx`
- `med_snr_local_scale_delta_percent_corr.xlsx`
- `med_connectivity_scale_delta_percent_corr.xlsx`

Each workbook must contain aligned `r` and `p_raw` sheets. The heatmaps use
Spearman rho as the color value and raw `p_raw` values for significance stars.

## Axis Labels

The x-axis uses the same feature order as the statistical workflow and compact
unitless labels adapted from the resting-state correlation heatmaps. Because
the LFP variables are medication-induced changes, all x-axis LFP labels are
displayed with a leading `Δ`.

Band-level aperiodic power columns are excluded. `Exponent` and `Offset`
remain included in the local STN and SNr heatmaps.

The y-axis display labels are:

```text
LCT Δ%
UPDRS III Δ%
Axial Δ%
Rigidity Δ%
Bradykinesia Δ%
Rest tremor Δ%
Action tremor Δ%
```

The combined-tremor heatmaps use:

```text
LCT Δ%
UPDRS III Δ%
Axial Δ%
Rigidity Δ%
Bradykinesia Δ%
Tremor Δ%
```

The top strip labels are:

```text
STN
SNr
SNr-STN / SNr->STN
```

## Style

Heatmaps reuse the compact well-heatmap style used by the resting-state
correlation figures:

- symmetric Spearman rho color range from `-1` to `1`;
- `cm.vik` colormap;
- black grid lines;
- `Spearman's rho` colorbar label;
- significance stars from raw p-values, with non-significant labels hidden.

## Outputs

Outputs are written to:

```text
${MYLFP_PROJECT_ROOT}/summary/stats/med/corr
```

Generated heatmaps:

- `med_stn_local_scale_delta_percent_corr_heatmap.pdf`

- `med_snr_local_scale_delta_percent_corr_heatmap.pdf`
- `med_snr_local_scale_delta_percent_corr_heatmap.png`
- `med_connectivity_scale_delta_percent_corr_heatmap.pdf`
- `med_connectivity_scale_delta_percent_corr_heatmap.png`
- `med_stn_local_scale_combined_tremor_delta_percent_corr_heatmap.pdf`
- `med_stn_local_scale_combined_tremor_delta_percent_corr_heatmap.png`
- `med_snr_local_scale_combined_tremor_delta_percent_corr_heatmap.pdf`
- `med_snr_local_scale_combined_tremor_delta_percent_corr_heatmap.png`
- `med_connectivity_scale_combined_tremor_delta_percent_corr_heatmap.pdf`
- `med_connectivity_scale_combined_tremor_delta_percent_corr_heatmap.png`

## Run Command

Use the MyLFP default Conda environment:

```bash
conda run -n LFP python recipes/stnsnr/viz/med/med_scale_correlation.py
```

To render only the three additional combined-tremor heatmaps without
rewriting the existing heatmaps, use:

```bash
conda run -n LFP python recipes/stnsnr/viz/med/med_scale_correlation.py --combined-tremor-only
```
