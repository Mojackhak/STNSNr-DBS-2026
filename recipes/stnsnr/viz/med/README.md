# STN/SNr Medication Visualizations

These scripts generate medication-state figures from
`${MYLFP_PROJECT_ROOT}/summary/stats/med`.

## Current Grouping Variables

`Hemi` is not used as a visualization grouping, panel, or facet variable in
the medication visualization recipes.

- `single_scalar.py` draws raw `Med-Region` plots and normalized `Region`
  plots.
- `double_scalar.py` draws raw `Med` plots only.
- `single_spectral.py` draws raw `Med-Region` plots and normalized `Region`
  plots.
- `double_spectral.py` draws raw `Med` plots only.

The scripts no longer generate `Hemi`, `Med-Hemi`, `Hemi-Region`, or
`Med-Region-Hemi` figures. Existing legacy files with those names are kept
unless they are explicitly removed outside these scripts.

## XYZ Region Figures

`single_xyz.py` and `double_xyz.py` render normalized medication-state MNI
coordinate slope figures as separate outputs for each available `Region`. The
scripts read existing `zMX/zMY/zMZ-Region` model curve and slope CSV files,
filter the loaded feature table and model outputs to one region at a time, and
save per-region files such as `zMX-Region-STN_norm.pdf`.

See `med_xyz_region_figures.md` for inputs, output naming, and run commands.

## Scalar and Spectral Region Figures

`single_scalar.py`, `double_scalar.py`, `single_spectral.py`, and
`double_spectral.py` keep their combined region-panel outputs and also write
separate PDFs for each available `Region` when `Region` is used as the panel
variable. Region-as-x-axis summary plots are not split.

See `med_scalar_spectral_region_figures.md` for inputs, output naming, and run
commands.

## LFP-Scale Delta Percent Correlation Heatmaps

`med_scale_correlation.py` renders the STN local, SNr local, and connectivity
correlation heatmaps generated by the medication stats correlation workflow.
The heatmaps use Spearman rho colors and raw p-values for significance stars.
The LFP x-axis labels use a leading `Δ` because the plotted LFP variables are
medication-induced changes. Band-level aperiodic power is excluded from the
local STN/SNr heatmaps, while `Exponent` and `Offset` remain included.

## MNI Standardized Slope Heatmaps

`med_mni_standardized_slope_heatmap.py` renders STN and SNr MNI-coordinate
gradient heatmaps from the standardized-slope table generated by the medication
stats workflow. The heatmaps use standardized slopes as colors and `q` values
for significance stars. In addition to separate x, y, and z coordinate
heatmaps, the script writes STN and SNr combined xyz summaries with three
top-strip coordinate panels and no right strip.

## Signed-LogP Heatmaps

`medon_vs_medoff_signed_logp_heatmap.py` renders the signed-logP intermediate
table generated by the medication stats workflow. The heatmaps use the same
compact well-heatmap style as the resting-state LAH-vs-MAH signed-logP summary,
with colorbar endpoint labels `ON > OFF` and `ON < OFF`.
