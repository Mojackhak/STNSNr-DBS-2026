# MedON vs MedOFF Signed-LogP Heatmaps

## Purpose

This visualization renders medication-state signed-logP heatmaps from the
intermediate table generated by:

```text
recipes/stnsnr/stats/med/medon_vs_medoff_signed_logp.py
```

It creates separate heatmaps for:

- `STN`
- `SNr`
- `SNr-/->STN`
- `Params`

## Input

The renderer reads:

```text
${MYLFP_PROJECT_ROOT}/summary/stats/med/corr/med_medon_vs_medoff_signed_logp_values.csv
```

The input table must use `rlmer_model` sources and the source contrast
`Off - On`. The stored estimates are already flipped so positive signed-logP
values mean `MedON > MedOFF`.

## Matrix Order

Frequency-band columns are ordered as:

```text
Delta, Theta, Alpha, Beta_low, Beta_high, Gamma
```

The displayed x-axis labels follow the rest signed-logP heatmap style:

```text
delta symbol, theta symbol, alpha symbol, Low-beta, High-beta, gamma symbol
```

Local metric rows are:

```text
raw, period, burst-occupation, burst-rate, burst-duration, burst-mean
```

Connectivity metric rows are:

```text
coh, wpli, ciplv, delta_net_gc, psi
```

The parameter heatmap uses columns `Exponent` and `Offset`, with rows `SNr` and
`STN`.

## Encoding

Heatmap colors use signed-logP values clipped to a symmetric range of `[-4, 4]`.
The colorbar endpoint labels are exactly:

```text
ON > OFF
ON < OFF
```

The central colorbar label is:

```text
Signed -log10(p_Tukey)
```

Significance stars come from `p_tukey`, and non-significant cells remain
colored by signed-logP.

## Outputs

Outputs are written to:

```text
${MYLFP_PROJECT_ROOT}/summary/stats/med/corr
```

Generated heatmaps:

- `med_stn_local_medon_vs_medoff_signed_logp_heatmap.pdf`
- `med_stn_local_medon_vs_medoff_signed_logp_heatmap.png`
- `med_snr_local_medon_vs_medoff_signed_logp_heatmap.pdf`
- `med_snr_local_medon_vs_medoff_signed_logp_heatmap.png`
- `med_connectivity_medon_vs_medoff_signed_logp_heatmap.pdf`
- `med_connectivity_medon_vs_medoff_signed_logp_heatmap.png`
- `med_params_medon_vs_medoff_signed_logp_heatmap.pdf`
- `med_params_medon_vs_medoff_signed_logp_heatmap.png`

## Run Command

Use the MyLFP default Conda environment:

```bash
conda run -n LFP python recipes/stnsnr/viz/med/medon_vs_medoff_signed_logp_heatmap.py
```
