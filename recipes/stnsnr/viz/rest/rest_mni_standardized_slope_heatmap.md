# Rest MNI Standardized Slope Heatmaps

## Purpose

This visualization renders standardized resting-state MNI-coordinate slope
effects as ten heatmaps. Six single-coordinate heatmaps summarize
frequency-resolved metric families:

```text
zSTN-x
zSTN-y
zSTN-z
zSNr-x
zSNr-y
zSNr-z
```

Two additional combined frequency heatmaps place the x, y, and z coordinate
gradients side by side:

```text
zSTN-x/y/z
zSNr-x/y/z
```

Two additional heatmaps summarize aperiodic parameters:

```text
STN
SNr
```

The plotting script does not compute statistics. It reads the standardized
slope table generated by `rest_mni_standardized_slope.py`.

## Input

The required input table is:

```text
${MYLFP_PROJECT_ROOT}/summary/stats/rest/corr/rest_mni_standardized_slope_values.csv
```

The heatmap value is always `standardized_slope_display`, a clipped version of:

```text
standardized_slope = slope / SD(Value within Band, Region)
```

Significance stars use the original `rlmer_model` slope `q` column.

## Matrix Layout

For the six frequency-resolved heatmaps, the x-axis order is:

```text
Delta, Theta, Alpha, Beta_low, Beta_high, Gamma
```

The displayed x-axis labels are:

```text
δ, θ, α, Low-β, High-β, γ
```

The y-axis metric order is:

```text
raw, period, burst-occupation, burst-rate, burst-duration, burst-mean,
coh, wpli, ciplv, delta_net_gc, psi
```

Metric labels are carried through from the standardized-slope table and follow
the existing rest LAH vs MAH heatmap style. The combined xyz heatmaps use a
single-row, three-column panel grid with top strips for zSTN-x/y/z or
zSNr-x/y/z. They do not use right strips, because there is no second paneling
variable. Y-axis labels are shown on the left coordinate panel only.

For the two aperiodic parameter heatmaps, the x-axis order is:

```text
Exponent, Offset
```

The y-axis order is:

```text
MNI-x (z-scored)
MNI-y (z-scored)
MNI-z (z-scored)
```

The parameter heatmap x-axis labels are rotated 90 degrees for the compact
two-column panel.

## Visual Encoding

The heatmaps use:

- `cm.vik`, centered at zero;
- fixed symmetric color limits `[-1, 1]`;
- `4.0 x 4.0 mm` cells;
- top strip style from `visualdf.py` and `viz_defaults.py`;
- the shared `visualdf.plot_well_heatmap_grid_df` backend for the combined xyz
  heatmaps;
- colorbar label `Standardized slope` with an 8 mm label offset;
- no direction labels at the colorbar ends.

Stars are:

```text
*   q < 0.05
**  q < 0.01
*** q < 0.001
```
