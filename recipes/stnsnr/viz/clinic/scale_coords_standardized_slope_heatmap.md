# Clinic Coordinate Scale Standardized-Slope Heatmaps

## Purpose

This workflow summarizes how 3-month clinical improvement rates vary along
standardized MNI coordinates in the clinic coordinate scale outputs. It renders
two heatmaps:

```text
STN 3m improvement
STN+SNr 3m additional improvement
```

The plotting script does not fit models. It reads the standardized-slope table
generated by `scale_coords_standardized_slope.py`.

## Input

The source directory is:

```text
${MYLFP_PROJECT_ROOT}/summary/stats/clinic/coords/scale
```

Only 3-month improvement-rate folders are used. Immediate folders are excluded.

STN-only improvement folders contain `Δ%` and do not start with `Δ`:

```text
UPDRS-III Δ% (STN, 3m)
UPDRS-III axial Δ% (STN, 3m)
FOG-Q Δ% (STN, 3m)
MADRS Δ% (STN, 3m)
KPPS Δ% (STN, 3m)
ADL Δ% (STN, 3m)
SE-ADL Δ% (STN, 3m)
PDQ-39 Δ% (STN, 3m)
```

STN+SNr additional-improvement folders contain `Δ%` and start with `Δ`:

```text
ΔUPDRS-III Δ% (+SNr, 3m)
ΔUPDRS-III axial Δ% (+SNr, 3m)
ΔFOG-Q Δ% (+SNr, 3m)
ΔMADRS Δ% (+SNr, 3m)
ΔKPPS Δ% (+SNr, 3m)
ΔADL Δ% (+SNr, 3m)
ΔSE-ADL Δ% (+SNr, 3m)
ΔPDQ-39 Δ% (+SNr, 3m)
```

Each folder must contain:

```text
scale_subject_{scale}.xlsx
lm_model/zMX_slope.csv
lm_model/zMY_slope.csv
lm_model/zMZ_slope.csv
```

The subject workbook must contain `ID`, `Region`, `Scale`, and `Value`.

## Standardization

The heatmap value is:

```text
standardized_slope = slope / SD(Value)
```

`SD(Value)` is calculated within each scale folder from non-missing subject-level
`Value` entries. The display value is clipped to:

```text
[-1, 1]
```

Significance stars use the `q` column from each existing `lm_model/*_slope.csv`
file:

```text
*   q < 0.05
**  q < 0.01
*** q < 0.001
```

## Matrix Layout

Rows follow the existing rest efficacy-correlation order and use shorter labels:

```text
UPDRS-III Δ%
UPDRS-III axial Δ%
FOG-Q Δ%
MADRS Δ%
KPPS Δ%
ADL Δ%
SE-ADL Δ%
PDQ-39 Δ%
```

The STN+SNr heatmap keeps the leading `Δ` in the displayed row labels.

Columns are:

```text
MNI-x (scored)
MNI-y (scored)
MNI-z (scored)
```

## Visual Encoding

The heatmaps use:

- `cm.vik`, centered at zero;
- fixed symmetric color limits `[-1, 1]`;
- `3.0 x 3.0 mm` cells;
- top strip style from `visualdf.py` and `viz_defaults.py`;
- top strip labels `STN` and `+SNr`;
- colorbar label `Standardized slope`.

## Outputs

Outputs are written to:

```text
${MYLFP_PROJECT_ROOT}/summary/stats/clinic/coords/scale
```

Generated standardized-slope table:

- `scale_3m_efficacy_standardized_slope_values.csv`

Generated heatmaps:

- `scale_stn_3m_efficacy_standardized_slope_heatmap.pdf`
- `scale_stn_3m_efficacy_standardized_slope_heatmap.png`
- `scale_stn_snr_3m_delta_efficacy_standardized_slope_heatmap.pdf`
- `scale_stn_snr_3m_delta_efficacy_standardized_slope_heatmap.png`

## Run Commands

Use the MyLFP default Conda environment:

```bash
conda run -n LFP python recipes/stnsnr/stats/clinic/scale_coords_standardized_slope.py
conda run -n LFP python recipes/stnsnr/viz/clinic/scale_coords_standardized_slope_heatmap.py
```
