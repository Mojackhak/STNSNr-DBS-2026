# Gait Phase Swing vs Stance Signed-LogP Heatmaps

## Purpose

This visualization renders gait-phase `Phase` signed-logP heatmaps from the
intermediate table generated by:

```text
recipes/stnsnr/stats/gait_phase/gait_phase_phase_swing_vs_stance_signed_logp.py
```

Positive signed-logP values mean `Swing > Stance`.

## Input

The renderer reads:

```text
${MYLFP_PROJECT_ROOT}/summary/stats/gait_phase/corr/phase_swing_vs_stance/gait_phase_phase_swing_vs_stance_signed_logp_values.csv
```

The input table must use `rlmer_model` sources and source contrast
`Stance - Swing`.

## Figure Layout

All heatmaps use:

- top strips ordered `Ipsi`, `Contra`;
- `3.0 x 3.0 mm` cells;
- black solid grid lines;
- display values clipped to `[-3, 3]`;
- the shared `visualdf.plot_well_heatmap_grid_df` backend.

Frequency-band columns exclude `Delta` and are ordered as:

```text
Theta, Alpha, Beta_low, Beta_high, Gamma
```

The renderer creates individual heatmaps for `STN`, `SNr`, `SNr-/→STN`, and
`Params`. It also creates a second Params heatmap whose top strips are ordered
`SNr`, `STN`; each panel uses y-axis rows `Ipsi`, `Contra` and parameter
columns `Exponent`, `Offset`.

It also creates a transposed Params heatmap whose top strips are ordered
`Ipsi`, `Contra`; each panel uses y-axis rows `Exponent`, `Offset` and x-axis
columns `SNr`, `STN`.

It also creates a summary heatmap with right strips ordered:

```text
SNr, STN, SNr-/→STN
```

Params are not included in the summary heatmap.

## Encoding

The shared colorbar is labeled:

```text
Signed -log10(p_Tukey)
```

The colorbar endpoint labels are:

```text
Swing > Stance
Swing < Stance
```

Significance stars come from `p_tukey`.

## Outputs

Heatmap files are written to:

```text
${MYLFP_PROJECT_ROOT}/summary/stats/gait_phase/corr/phase_swing_vs_stance
```

Generated heatmap basenames:

- `gait_phase_phase_stn_local_swing_vs_stance_signed_logp_heatmap`
- `gait_phase_phase_snr_local_swing_vs_stance_signed_logp_heatmap`
- `gait_phase_phase_connectivity_swing_vs_stance_signed_logp_heatmap`
- `gait_phase_phase_params_swing_vs_stance_signed_logp_heatmap`
- `gait_phase_phase_params_by_region_swing_vs_stance_signed_logp_heatmap`
- `gait_phase_phase_params_transposed_swing_vs_stance_signed_logp_heatmap`
- `gait_phase_phase_summary_swing_vs_stance_signed_logp_heatmap`

Each basename is exported as PDF and PNG.

## Run Command

Use the MyLFP default Conda environment:

```bash
conda run -n LFP python recipes/stnsnr/viz/gait_phase/gait_phase_phase_swing_vs_stance_signed_logp_heatmap.py
```
