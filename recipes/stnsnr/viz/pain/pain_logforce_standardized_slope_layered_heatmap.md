# Pain LogForce Standardized-Slope Layered Heatmaps

## Purpose

This visualization renders BL-normalized pain `LogForce` standardized-slope
heatmaps from the intermediate table generated by:

```text
recipes/stnsnr/stats/pain/pain_logforce_standardized_slope.py
```

The renderer uses the shared
`src.viz.visualdf.plot_well_heatmap_grid_df` backend for every figure.

## Input

The required input table is:

```text
${MYLFP_PROJECT_ROOT}/summary/stats/pain/corr/logforce_standardized_slope/pain_logforce_standardized_slope_values.csv
```

The heatmap value is `standardized_slope_display`, a clipped version of:

```text
standardized_slope = slope / SD(BL-normalized Value)
```

Significance stars use the original `rlmer_model` slope `q` column.

## Figure Layout

Layered heatmaps stack pain phases as right strips in this order:

```text
ONS, SUS, OFS, PST
```

The renderer creates original and transposed heatmaps for:

- `SNr`
- `STN`
- `SNr-/→STN`
- Params

It also creates one additional Params phase-by-region heatmap. This figure uses
top strips `SNr` and `STN`, y-axis rows `ΔExponent` and `ΔOffset`, and x-axis
columns `ONS`, `SUS`, `OFS`, `PST`.

Frequency bands are ordered as:

```text
Delta, Theta, Alpha, Beta_low, Beta_high, Gamma
```

The local y-axis metric order is:

```text
raw, period, burst-occupation, burst-rate, burst-duration, burst-mean
```

The connectivity y-axis metric order is:

```text
coh, wpli, ciplv, delta_net_gc, psi
```

It also creates one combined summary heatmap for `SNr`, `STN`, and
`SNr-/→STN`. Params are not included in the combined summary heatmap.

The combined summary uses right strips ordered `ONS`, `SUS`, `OFS`, `PST`; top
strips ordered `SNr`, `STN`, `SNr-/→STN`; y-axis bands; and x-axis metric
labels.

Metric labels and parameter labels are displayed with a leading `Δ`, for
example `ΔTotal power`, because the modeled values are BL-normalized changes.

## Visual Encoding

The heatmaps use:

- `cm.vik`, centered at zero;
- fixed symmetric color limits `[-0.6, 0.6]`;
- `3.0 x 3.0 mm` cells;
- right strip labels ordered `ONS`, `SUS`, `OFS`, `PST`;
- the same well-grid, tick, spine, and significance-star drawing core as
  `plot_well_heatmap_df`;
- x-axis tick labels only on the bottom phase panel, while tick locations
  remain present in every panel;
- y-axis tick labels on every grouped panel and only on the left group column
  in the combined summary heatmap;
- colorbar label `Standardized slope of ΔLFP per centered log10(Force)`;
- no direction labels at the colorbar ends.

Stars are:

```text
*   q < 0.05
**  q < 0.01
*** q < 0.001
```

- `pain_logforce_stn_local_standardized_slope_freq_by_param_layered_heatmap`

```bash
conda run -n LFP python recipes/stnsnr/viz/pain/pain_logforce_standardized_slope_layered_heatmap.py
```
