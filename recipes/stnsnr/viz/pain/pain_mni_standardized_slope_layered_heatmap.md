# Pain MNI Standardized-Slope Layered Heatmaps

## Purpose

This visualization renders pain phase MNI-coordinate standardized-slope
heatmaps from the intermediate table generated by:

```text
recipes/stnsnr/stats/pain/pain_mni_standardized_slope.py
```

The renderer uses the shared
`src.viz.visualdf.plot_well_heatmap_grid_df` backend for every figure.

## Input

The required input table is:

```text
${MYLFP_PROJECT_ROOT}/summary/stats/pain/corr/mni_standardized_slope/pain_mni_standardized_slope_values.csv
```

The heatmap value is `standardized_slope_display`, a clipped version of:

```text
standardized_slope = slope / SD(Value within Band or parameter, Region, Phase)
```

Significance stars use the original `rlmer_model` slope `q` column.

## Figure Layout

All heatmaps stack pain phases as right strips in this order:

```text
ONS, SUS, OFS, PST
```

The single-coordinate frequency heatmaps use one coordinate top strip per
figure:

```text
zSNr-x, zSNr-y, zSNr-z
zSTN-x, zSTN-y, zSTN-z
```

The combined frequency heatmaps arrange panels as a `Phase x Coordinate` grid.
Top strips show `zSNr-x/y/z` or `zSTN-x/y/z`; y-axis metric labels are shown
only on the left coordinate column.

Frequency bands are ordered as:

```text
Delta, Theta, Alpha, Beta_low, Beta_high, Gamma
```

The y-axis metric order is:

```text
raw, period, burst-occupation, burst-rate, burst-duration, burst-mean,
coh, wpli, ciplv, delta_net_gc, psi
```

Pain `contact_normalized` values represent BL-relative phase changes. Frequency
metric labels are therefore displayed with a leading `Δ`, while the audit-table
`metric_label` values remain unchanged.

For the two aperiodic parameter heatmaps, the x-axis order is:

```text
ΔExponent, ΔOffset
```

The y-axis order is:

```text
MNI-x (z-scored)
MNI-y (z-scored)
MNI-z (z-scored)
```

The combined parameter heatmap arranges panels as a `Phase x Region` grid with
top strips ordered `SNr`, `STN`. Parameter column labels are displayed with a
leading `Δ`, while coordinate rows remain `MNI-x/y/z (z-scored)`.

Two additional per-region parameter heatmaps arrange panels as a
`Region-specific Coordinate` grid. Their top strips are `zSNr-x/y/z` or
`zSTN-x/y/z`, y-axis rows are `ΔExponent` and `ΔOffset`, and x-axis columns are
`ONS`, `SUS`, `OFS`, `PST`.

## Visual Encoding

The heatmaps use:

- `cm.vik`, centered at zero;
- fixed symmetric color limits `[-0.7, 0.7]`;
- `3.0 x 3.0 mm` cells;
- right strip labels ordered `ONS`, `SUS`, `OFS`, `PST`;
- the same well-grid, tick, spine, and significance-star drawing core as
  `plot_well_heatmap_df`;
- x-axis tick labels only on the bottom phase panel, while tick locations
  remain present in every panel;
- y-axis tick labels on every single-coordinate and per-region parameter
  panel, only on the left coordinate column in the combined frequency
  heatmaps, only on the left region column in the combined parameter heatmap,
  and only on the left coordinate column in the parameter phase-by-coordinate
  heatmaps;
- colorbar label `Standardized slope`;
- no direction labels at the colorbar ends.

Stars are:

```text
*   q < 0.05
**  q < 0.01
*** q < 0.001
```
