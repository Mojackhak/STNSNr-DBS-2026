# Pain LFP-KPPS 3-Month Correlation Heatmaps

## Purpose

This visualization renders multi-panel heatmaps for correlations between pain
LFP changes and KPPS clinical variables.

It reads the correlation workbooks generated by:

```text
recipes/stnsnr/stats/pain/pain_lfp_kpps_3m_correlation.py
```

It creates separate heatmaps for:

- `STN`
- `SNr`
- `SNr-STN / SNr->STN`

For each analysis group, the renderer writes the original three-row heatmap
and an additional improvement-only heatmap that excludes `Pre-op KPPS`.

## Inputs

The renderer reads correlation workbooks from:

```text
${MYLFP_PROJECT_ROOT}/summary/stats/pain/corr/pain_lfp_kpps_3m
```

Required workbooks:

- `pain_stn_local_kpps_3m_corr_by_phase.xlsx`
- `pain_snr_local_kpps_3m_corr_by_phase.xlsx`
- `pain_connectivity_kpps_3m_corr_by_phase.xlsx`

Each workbook must contain phase-specific aligned sheets:

```text
ONS_r, ONS_p, ONS_p_raw, ONS_p_adj, ONS_n
SUS_r, SUS_p, SUS_p_raw, SUS_p_adj, SUS_n
OFS_r, OFS_p, OFS_p_raw, OFS_p_adj, OFS_n
PST_r, PST_p, PST_p_raw, PST_p_adj, PST_n
```

Heatmap color uses Spearman rho from the `*_r` sheets. Significance stars use
uncorrected p-values from the `*_p_raw` sheets.

## Panel and Axis Labels

Each heatmap has four stacked panels ordered as:

```text
ONS
SUS
OFS
PST
```

The right strip labels the pain phase panel. Every panel represents an LFP
change relative to `BL`.

The x-axis uses the same feature order as the statistical workflow. Because
the LFP variables are phase-induced changes, all x-axis LFP labels are
displayed with a leading `Δ`.

Band-level aperiodic power columns are excluded. `Exponent` and `Offset`
remain included in the local STN and SNr heatmaps.

The y-axis labels are:

```text
Pre-op KPPS
KPPS Δ% (STN, 3m)
ΔKPPS Δ% (+SNr, 3m)
```

The improvement-only heatmaps use only:

```text
KPPS Δ% (STN, 3m)
ΔKPPS Δ% (+SNr, 3m)
```

The top strip labels are:

```text
STN
SNr
SNr-STN / SNr->STN
```

## Style

Heatmaps use the compact layered heatmap style used by the walking signed-logP
figures and the walking LFP-gait PCA correlation heatmaps. The renderer uses
the shared `visualdf.plot_well_heatmap_grid_df` backend and follows the same
drawing elements:

- symmetric Spearman rho color range from `-1` to `1`;
- `cm.vik` colormap;
- black solid cell grid lines using `linewidth=0.6` and `alpha=0.9`;
- `Spearman's rho` colorbar label;
- significance stars from raw p-values, with non-significant labels hidden;
- white significance stars;
- x-axis tick labels only on the bottom phase panel;
- y-axis tick labels on every phase panel;
- square `3.0 mm x 3.0 mm` cells.

## Run Command

Use the MyLFP default Conda environment:

```bash
conda run -n LFP python recipes/stnsnr/viz/pain/pain_lfp_kpps_3m_correlation_heatmap.py
```
