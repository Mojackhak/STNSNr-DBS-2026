# Pain Lat Ipsi-vs-Contra Signed-LogP Layered Heatmaps

## Purpose

This visualization renders BL-normalized pain `Lat` signed-logP heatmaps from
the intermediate table generated by:

```text
recipes/stnsnr/stats/pain/pain_lat_ipsi_vs_contra_signed_logp.py
```

## Input

The renderer reads:

```text
${MYLFP_PROJECT_ROOT}/summary/stats/pain/corr/lat_ipsi_vs_contra/pain_lat_ipsi_vs_contra_signed_logp_values.csv
```

The input table must use `rlmer_model` sources from the BL-normalized
`Lat-Phase` Tukey analysis and source contrast `Ipsi - Contra`.

## Figure Layout

All heatmaps use:

- four layered panels with right strips ordered `ONS`, `SUS`, `OFS`, `PST`;
- `3.0 x 3.0 mm` cells;
- black solid grid lines;
- display values clipped to `[-3, 3]`;
- the shared `visualdf.plot_well_heatmap_grid_df` backend.

Frequency bands are ordered as:

```text
Delta, Theta, Alpha, Beta_low, Beta_high, Gamma
```

The renderer creates original and transposed heatmaps for:

- `SNr`
- `STN`
- `SNr-/→STN`
- `Params`

The intermediate CSV may contain the `Aperiodic power` local metric, but this
metric is omitted from all rendered heatmaps.

Banded metric labels and parameter labels use a leading `Δ`, for example
`ΔTotal power`, because the displayed values are changes relative to BL.

It also creates one combined summary heatmap for `SNr`, `STN`, and
`SNr-/→STN`. Params are not included in the combined summary heatmap.

The combined summary uses right strips ordered `ONS`, `SUS`, `OFS`, `PST`; top
strips ordered `SNr`, `STN`, `SNr-/→STN`; y-axis bands; and x-axis metric
labels.

The renderer also creates one Params-by-region heatmap. This figure uses top
strips `SNr` and `STN`, y-axis rows `ΔExponent` and `ΔOffset`, and x-axis
columns `ONS`, `SUS`, `OFS`, and `PST`. It does not include `SNr-/→STN`
because the source `Lat-Phase-Region_tukey.csv` parameter rows only contain
region-level `SNr` and `STN` estimates.

## Encoding

The shared colorbar is labeled:

```text
Signed -log10(p_Tukey)
```

Positive values mean the BL-normalized `Ipsi` change is greater than the
BL-normalized `Contra` change; negative values mean the opposite. Significance
stars come from `p_tukey`.

## Outputs

Heatmap files are written to:

```text
${MYLFP_PROJECT_ROOT}/summary/stats/pain/corr/lat_ipsi_vs_contra
```

Generated heatmap basenames:

- `pain_lat_snr_local_ipsi_vs_contra_signed_logp_layered_heatmap`
- `pain_lat_stn_local_ipsi_vs_contra_signed_logp_layered_heatmap`
- `pain_lat_connectivity_ipsi_vs_contra_signed_logp_layered_heatmap`
- `pain_lat_params_ipsi_vs_contra_signed_logp_layered_heatmap`
- `pain_lat_snr_local_ipsi_vs_contra_signed_logp_freq_by_param_layered_heatmap`
- `pain_lat_stn_local_ipsi_vs_contra_signed_logp_freq_by_param_layered_heatmap`
- `pain_lat_connectivity_ipsi_vs_contra_signed_logp_freq_by_param_layered_heatmap`
- `pain_lat_params_ipsi_vs_contra_signed_logp_transposed_layered_heatmap`
- `pain_lat_summary_freq_by_param_ipsi_vs_contra_signed_logp_layered_heatmap`
- `pain_lat_params_by_region_ipsi_vs_contra_signed_logp_heatmap`

Each basename is exported as PDF and PNG.

Use the MyLFP default Conda environment:

```bash
conda run -n LFP python recipes/stnsnr/viz/pain/pain_lat_ipsi_vs_contra_signed_logp_layered_heatmap.py
```
