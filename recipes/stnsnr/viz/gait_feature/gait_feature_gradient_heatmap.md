# Gait Feature Gradient Heatmaps

## Purpose

This renderer plots standardized gait-feature gradient effects from the audit
tables generated by `gait_feature_gradient_standardized_slope.py`.

It processes both:

- `gait_feature`
- `gait_feature_linear`

Each gait feature is rendered separately:

- `Walk_speed`
- `Stride_length`
- `Cycle_duration`

## Layout

For each stats root and gait feature, the renderer creates eight figures:

- STN local
- SNr local
- connectivity
- frequency summary
- frequency summary transposed
- params
- params by gradient
- params by region

Frequency figures use metric rows and frequency-band columns. Displayed metric
rows use a leading `Δ` because the plotted LFP values are changes relative to
Stand. Frequency heatmaps exclude the `Delta` band and use:

```text
Theta, Alpha, Beta_low, Beta_high, Gamma
```

Burst row scope differs by root. `gait_feature` includes
`ΔBurst occupation`, `Δasinh burst rate`, `Δln burst duration`, and
`Δln burst amplitude`; `gait_feature_linear` includes only
`ΔBurst occupation` and `Δln burst amplitude`.

The frequency summary heatmap uses a variable-height `3 x 2` panel grid with
top strips `Between`, `Within` and right strips `SNr`, `STN`, `SNr-/→STN`.

The transposed frequency summary heatmap uses a `2 x 3` panel grid with top
strips `SNr`, `STN`, `SNr-/→STN` and right strips `Between`, `Within`. Within
each panel, y-axis rows are frequency bands and x-axis columns are LFP metrics.

The params heatmap uses top strips `SNr`, `STN`, rows `Between`, `Within`, and
columns `ΔExponent`, `ΔOffset`.

The params-by-gradient heatmap uses top strips `Between`, `Within`, y-axis rows
`SNr`, `STN`, and columns `ΔExponent`, `ΔOffset`.

The params-by-region heatmap uses top strips `Between`, `Within`, y-axis rows
`ΔExponent`, `ΔOffset`, and columns `SNr`, `STN`.

## Visual Encoding

The heatmaps use:

- `cm.vik`, centered at zero;
- fixed symmetric color limits `[-0.6, 0.6]`, chosen to cover the current
  standardized-slope extrema without clipping;
- `3.0 x 3.0 mm` cells;
- the shared `visualdf.plot_well_heatmap_grid_df` backend;
- per-feature colorbar labels such as
  `Standardized slope of ΔLFP (Walk - Stand) per z-scored walk speed`;
- white q-value significance stars.

## Outputs

Figures are written under each root:

```text
${MYLFP_PROJECT_ROOT}/summary/stats/gait_feature/corr/gait_standardized_slope
${MYLFP_PROJECT_ROOT}/summary/stats/gait_feature_linear/corr/gait_standardized_slope
```

The renderer creates 96 files total:

```text
2 stats roots x 3 gait features x 8 heatmaps x PDF/PNG
```

## Run Command

Use the MyLFP default Conda environment:

```bash
conda run -n LFP python recipes/stnsnr/viz/gait_feature/gait_feature_gradient_heatmap.py
```

## Compact parameter colorbars

Two-row parameter heatmaps show only the negative endpoint, zero, and positive
endpoint colorbar ticks. The previous five ticks overlap on a two-cell-high
colorbar. This display-only change preserves color limits, cell sizes, values,
and significance markers; larger metric grids retain all existing ticks.
