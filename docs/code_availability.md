# Code availability information

Custom analysis and visualization code is organized on the `nn2026` branch,
extracted from MyLFP commit `986358b112dcd2d032a55a425702049aa3a6c5a8`.
Original included code retains the MIT license. This local preparation does not
create a public release, DOI or access-controlled reviewer link.

Before submission, supply the actual repository/archive location and identify
the fixed source snapshot used for the paper. The deposited materials should
include the README, environment information, synthetic demo, figure-to-code
index and documented access restrictions. State separately how restricted study
data can be obtained and which analyses remain outside the code deposit.

The meta-analysis code/project has not been supplied in this snapshot. Do not
use wording claiming that all custom analyses are publicly available until that
material and the other documented gaps are resolved.

Relevant publisher guidance:

- [Nature Portfolio reporting and code availability policy](https://www.nature.com/nature/editorial-policies/reporting-standards)
- [Guidelines for authors submitting code and software](https://www.nature.com/documents/GuidelinesCodePublication.pdf)
- [Springer Nature code sharing policy](https://support.nature.com/en/support/solutions/articles/6000237619-software-and-code-sharing)

These sources describe availability of central custom code, installation and
system requirements, a runnable example, documentation, licensing and persistent
identification. Final acceptable sharing arrangements are determined by the
journal; this repository does not assert editorial approval.
